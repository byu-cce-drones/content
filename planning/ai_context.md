# AI Context

Read this before editing any course content.

## What this repository is

- Source for a Read the Docs site built with **MkDocs** (`readthedocs` theme). Config lives in
  `mkdocs.yml`; the build environment is in `readthedocs.yaml` and `docs/requirements.txt`.
- All published content is Markdown under `docs/`. The **readings** are organized by week
  (`docs/week_01/` through `docs/week_06/`). Alongside them sit `docs/labs/` (the lab sessions),
  `docs/final_project/`, `docs/class_resources/` (syllabus and TAs), and
  `docs/flight_check_list/`, which has its own overview page.
- Figures are SVG. Some are written by hand; the Topic 1 set is generated by scripts in `fig_tools/`
  (outside `docs/`, so MkDocs never publishes them) and committed as SVG under
  `docs/week_NN/images/`. See `instructions.md` for the style rules.
- The site is the homework and exercise companion to the class. The BYU Learning Suite schedule
  links into these pages.

## The course

- **Title:** BYU CCE Drone Measurements.
- **Audience:** freshman Civil Engineering and Construction Management students. Assume no prior
  drone, GIS, or surveying experience.
- **Format:** one-credit-hour introductory course. Each week is a short lecture plus a lab or
  exercise. Content must fit in roughly one hour of class contact time per week.
- **Central theme:** drones are *measurement instruments* for engineers. Every page should connect
  back to the question "is this data appropriate, reliable, and defensible for the decision at hand?"
  Accuracy versus effort (pacing vs. GPS vs. drone) is a recurring idea.

## Topics (as of September 2026)

The course runs over a 14-week semester, but the material is organized by **topic**, not by week.
Some topics take one class, others take several, so the nav says "Topic 1", "Topic 2" and so on.

| Topic | Subject | Pages |
|-------|---------|-------|
| 1 | Getting started | Welcome, Aerial Measurement Products, Flight Basics, Common Flight Issues |
| 2 | Software | Bentley iTwin, QGIS measurements |
| 3 | Measurements | Measurement lab, metadata |
| 4 | Mission planning | How Photos Become 3D, Planning the Flight |
| 5 | FAA Part 107 | Exam overview, knowledge review, resources, practice exams and instructor keys |
| 6 | Specialized sensors | LiDAR, thermal, multispectral |

**Note on folder names.**
Folders are still named `docs/week_01/` and figures still carry a `w01_` prefix. That is
deliberate. The BYU Learning Suite schedule links directly into these page URLs, and renaming
the folders would break every one of those links. The folder name is an internal path; what
students see is the nav label and the page title, and those say "Topic".

The authoritative nav order is the `nav:` block in `mkdocs.yml`. Update it whenever a page is
added, renamed, or removed.

## Hardware and software referenced

- **Aircraft:** DJI Mini series (sub-250 g). Recreational rules are simple for this class of
  aircraft, but the course still teaches Part 107.
- **Software:** Bentley iTwin, QGIS, SfM photogrammetry tools.
- **Regulatory:** FAA Part 107 (small UAS rule). The Topic 5 material tracks the FAA Airman
  Knowledge Testing Supplement (FAA-CT-8080-2H). The full PDF is git-ignored; a reduced copy
  lives in `docs/week_05/images/`.

## Markdown features in use

Enabled in `mkdocs.yml`: `admonition` (used heavily for "Key Takeaways" blocks), `attr_list`,
`md_in_html`, `sane_lists`, `pymdownx.arithmatex` (MathJax), `pymdownx.tasklist`, `pymdownx.emoji`.
Custom styling is in `docs/css/custom.css`; MathJax config is in `docs/js/mathjax-config.js`.

## There is a second repository

`https://byu-cce-aerial-measurements.readthedocs.io` is the site students see today, and it does
**not** build from this repository. It builds from `github.com/byu-cce-drones/content`, a separate
repository maintained by the TAs. The two share no commits; material was hand-copied between them at
some point, so several pages exist in both in different states.

This repository is not currently published anywhere. Which one becomes canonical is an open
instructor decision as of September 2026. Until it is settled, assume work done here is **not**
visible to students.

The labs, syllabus and TA pages in this repository were brought across from that one on 2026-09-03.
A clone of it sits in `.claude/local/content_repo/` (git-ignored), with an inventory in
`.claude/local/SOURCE_MATERIAL.md`.

  Do not add or move exam answers without checking with the instructor.

  need their captions and credits preserved.
