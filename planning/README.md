# Planning

Tracked planning material for the **BYU CCE Drone Measurements** course site. Nothing in this
folder is published: MkDocs only builds `docs/`, so this folder is safe for notes, context, and
working instructions that should travel with the repository.

| File | Purpose |
|------|---------|
| [ai_context.md](ai_context.md) | Background an AI assistant (or a new TA) needs before touching course content |
| [instructions.md](instructions.md) | Conventions for writing and editing course pages |
| [backlog.md](backlog.md) | Open items, ideas, and known gaps |

The root [CLAUDE.md](../CLAUDE.md) points Claude Code at these files so they load automatically.

Personal or throwaway Claude files (scratch, drafts, session notes) belong in `.claude/local/`,
which is git-ignored. Keep this folder for things the whole team should see.
