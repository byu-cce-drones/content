## Planning your time

- **Before your flight:** proposal approved, flight plan loaded, roles decided, checklist printed.
- **Flight week:** fly, then start processing **that same week**. Bentley processing can run for
  hours, and the lab machines are shared.
- **Work days (Nov 24, Dec 3):** finish your products, then start the slides and memo. TAs are in
  EB 321 to help.
- **Need more processing time?** Contact the TAs early. The last week fills up.
