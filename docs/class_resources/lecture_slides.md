# Lecture Slides

!!! abstract "Key Takeaways"
    - Every Tuesday lecture has a slide deck built alongside the reading it accompanies; this page
      collects links to all of them in one place.
    - A deck is a **subset** of that week's reading, built for fifty minutes in a room — read the
      reading first, and use the slides as the lecture's outline, not a substitute.
    - Slides are posted as they are written, so most rows below read "not yet posted" until that
      week's lecture is built.
